# Checkliste

Beim Putzen der Klasse ist zu erledigen:

- Aufräumen
- Spinnweben entfernen
- Tassen abwaschen und abtrocknen
- Lampenschirme reinigen
- alle Flächen säubern (Schränke, Ablagen, Fensterbrett, Tafel, etc.)
- Waschbecken schrubben
- Tische abwischen
- Sitzflächen der Stühle abwischen
- Fenster putzen, soweit notwendig
- Vorraum reinigen (Jacken- und Schuhregal staubsaugen)
- Staubsaugen
- Wischen
- Mülleimer leeren

Dieselbe Liste steht als Vorlage für Issues bereit: Auf GitHub unter "Issues" →
"New issue" → "Klasse putzen". Dann lässt sich abhaken, was erledigt ist.
